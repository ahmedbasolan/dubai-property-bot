11 / Guidelines

Do's & Don'ts

Maintain brand consistency by following these essential rules.

Do
  • Use Cinzel for all headings and display text
  • Maintain clear space around the logo
  • Use semantic colors (green/yellow/red) for investment signals
  • Apply glassmorphism effects on dark backgrounds
  • Use the spacing scale consistently (4/8/16/24/32/48/64px)
  • Include data freshness disclaimers on all metrics
  • Use 1.5px stroke weight for all custom icons
  • Test contrast ratios (minimum 4.5:1 for text)
Don't
  • Use emojis as icons or decorative elements
  • Skip hover/focus transitions on interactive elements
  • Use random spacing — follow the token scale
  • Hardcode colors — always use CSS variables
  • Use low-contrast text (below 4.5:1 ratio)
  • Present LLM-computed yield as deterministic data
  • Use warm/orange tones in imagery
  • Apply glassmorphism on light backgrounds
12 / Voice

Voice & Tone

How we communicate reflects our brand: authoritative but accessible, data-driven but human.

Brand Voice
Expert Advisor
Confident, knowledgeable, trustworthy. Never condescending or overly technical.
Tone
Professional + Warm
Formal enough for investors, friendly enough for first-time buyers.
Vocabulary
Domain-Specific
Use real estate terms (yield, ROI, DLD) but explain them on first use.
Confidence
Always Cited
Every claim backed by data. Always include confidence scores.

Writing Examples

✓ DO

"International City shows a 7.68% net yield — above the market average of 6.2%. However, high supply pipeline (15.5%) warrants caution. Confidence: High."

✗ DON'T

"This area is really good for investment!! You should definitely buy here before it's too late!"

Elements exiting screen

Animation Rules

Do
  • Fade in content on page load (stagger children)
  • Slide sidebar from left on mobile
  • Animate chart data points on load
  • Scale buttons slightly on hover (1.02)
  • Use skeleton loaders for async content
Don't
  • Auto-play videos or animations
  • Use bounce or elastic on data elements
  • Spin or rotate UI elements
  • Flash or strobe any element
  • Animate more than 3 elements simultaneously

Accessibility

Inclusive design ensures every investor can use our platform effectively.

WCAG 2.1 AA Compliance

Contrast Ratio
4.5:1
Minimum for normal text. 3:1 for large text.
Focus Indicators
2px ring
Visible focus ring on all interactive elements.
Touch Targets
44×44px
Minimum size for all clickable elements.
Text Scaling
200%
Content must reflow at 200% zoom.

Keyboard Navigation

Tab Order
Logical + Sequential
Follow visual layout. Skip hidden elements.
Skip Link
First Element
"Skip to main content" on every page.
Escape Key
Close Modals
All overlays dismissible with Escape.
Arrow Keys
Navigate Lists
Up/Down in menus, tables, charts.

Screen Reader Support

Do
  • Use semantic HTML (nav, main, section, article)
  • Add aria-labels to icon-only buttons
  • Announce dynamic content with aria-live
  • Provide alt text for all images
  • Use aria-describedby for complex data
Don't
  • Use divs for interactive elements
  • Hide focus indicators with outline: none
  • Use color alone to convey information
  • Auto-focus elements without user action
  • Use aria-hidden on focusable elements

Reduced Motion

@media (prefers-reduced-motion: reduce)

* { animation: none !important; transition: none !important; }

Respect user preference. Disable all non-essential animations.

Data Animations

Charts should still render data, but skip the entrance animation. Numbers should appear instantly, not count up.
